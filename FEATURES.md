## 🚫 Known Limitations (By Design for Demo)

1. **Payment Processing**: Simulated only (no real payment gateway)
2. **Email Notifications**: Not implemented (demo project)
3. **Image Upload**: Uses URLs instead of file uploads
4. **Inventory Alerts**: No low stock notifications
5. **Reviews & Ratings**: Not implemented
6. **Advanced Analytics**: Basic admin only
7. **Multi-currency**: USD only
8. **Shipping Calculator**: Free shipping only
9. **Tax Calculation**: Not implemented
10. **Guest Checkout**: Requires registration
